# Simple Blank Template — правила проекта

Шаблон-конструктор для Joomla 6+

## Структура проекта

```
simple_blank_template/
  .wiki - wiki описание проекта
```

## Стек

- CMS: Joomla 6
- Frontend: Uikit 3.x

## Локальные пути

- Дистрибутив Joomla (справка): `d:\distr\Joomla\6`
- PHP: `d:\portapps\dev`


## Обязательные правила

1. Диалог вести на **русском** языке
2. **Сервер и БД только для чтения.** Ничего не менять на сервере или в БД без явной команды пользователя.
3. **Не коммитить и не выводить в код секреты**: пароли, ключи SSH, токены 
4. При работе с Joomla использовать конвенции API Joomla (Joomla\CMS\*, DatabaseDriver и т.д.), а не прямые вызовы глобальных переменных.
5. Не дублировать код: переопределения шаблонов предпочтительнее правок ядра.
